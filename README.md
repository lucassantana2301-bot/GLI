# Volkswagen Jetta GLI — Website Conceitual Premium

Website conceitual de apresentação do **Volkswagen Jetta GLI (350 TSI)**, desenvolvido com foco em alta performance visual, tipografia forte e seções imersivas.

## ✨ Destaques
- **Abertura Cinematográfica:** Apresentação em tela cheia com tipografia monumental e dados de telemetria rápida (231 cv, 350 Nm, 0-100 km/h em 6,7s).
- **Engenharia & Chassi MQB:** Seção com imagem fixa (*sticky showcase*) e 4 capítulos técnicos dinâmicos (Diferencial VAQ, Suspensão Multi-link, Direção Progressiva e Freios de 312 mm).
- **Cockpit Digital:** Apresentação do interior esportivo com simulador interativo de iluminação ambiente.
- **Ficha Técnica Verificada:** Especificações completas do motor 2.0 TSI (EA888) homologado no Brasil e seletor de Modos de Condução (Eco, Comfort, Sport, Individual).
- **Galeria com Lightbox:** Visualizador de alta resolução com filtros por categoria e navegação por teclado (`Esc`, `←`, `→`).
- **Simulador Acústico 2.0 TSI:** Sintetizador procedural com Web Audio API que reproduz o ronco do motor e trocas com *pops* do câmbio DSG.
- **Animações Fluidas:** Integração com GSAP e ScrollTrigger respeitando `prefers-reduced-motion`.

## 🛠️ Tecnologias
- HTML5 Semântico
- CSS3 Moderno / Tailwind CSS
- JavaScript ES6+
- GSAP 3 & ScrollTrigger
- Web Audio API
